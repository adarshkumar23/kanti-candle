## ✦ The Story
I built this full-stack Next.js web application from scratch to bring our family's vision to life. **Kanti Candle** is more than just wax and wicks; it is a ritual, a memory, and a sanctuary of stillness. This digital storefront serves as the home for our creations, allowing everyone to experience our craft with effortless luxury.

## ✨ Key Features
* **AI Custom Candle Builder**: Powered by Google's Gemini API, users can type their dream candle concept and instantly visualize a photorealistic, bespoke creation!
* **Streamlined Shop**: A beautiful, modern e-commerce layout showcasing our signature collections (Floral, Woody, Oriental).
* **Admin Gallery Hub**: A secured, NextAuth-protected `/admin` dashboard perfectly engineered for our family to manage lifestyle photos and upcoming stock.
* **Razorpay Ready**: Integrated with Razorpay checkout so we can easily start processing orders in India when we go live.
* **Premium Aesthetics**: Fully customized Tailwind CSS architecture with modern typography (Cormorant Garamond, DM Sans) to mirror luxury boutique standards.

## 🛠️ Tech Stack
* **Frontend**: Next.js 15 (React), Tailwind CSS v4, TypeScript
* **Backend**: Next.js Server Actions, Prisma ORM, SQLite
* **Authentication**: NextAuth.js
* **Payments & AI**: Razorpay SDK, Google GenAI SDK

## 🚀 Getting Started Locally
To run this project on your own machine:

1. **Clone the repository**
2. **Install dependencies:** `npm install`
3. **Configure Environment Variables:** Add your keys to the `.env` file (Gemini API, Razorpay keys, NextAuth Secret).
4. **Push the Database:** `npx prisma db push`
5. **Start exploring:** `npm run dev`
